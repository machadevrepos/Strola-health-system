Super Admin Panel — Setup Guide

A walkthrough for running the Strolla Health Super Admin Panel on your own computer. No backend, no Firebase project, no Python — just double-click and go.

1

Node.js

The only thing to install — a one-time, five-minute step.

2

Super Admin Panel

Everything the day-to-day Admin Panel has, plus two elevated-only sections: Fleet (hardware provisioning) and Staff & Roles (granting/revoking admin access).

What this is: the panel runs entirely on its own, built-in sample data. There's no backend server, no Firebase project, and no Python or Java to install — just Node.js, and one double-click each time you want to open it.

Before you start

Install Node.js (one-time)

This is the only thing you need to install. If you've already got Node.js on this computer, skip straight to the next section.

1

Download and install Node.js

Go to nodejs.org and download the LTS version. Run the installer and click through with the defaults — nothing needs to be changed.

Step 1

Get the project files

1

Unzip the folder you were sent

Extract it somewhere easy to find, like your Desktop. You'll see a file called Start-Super-Admin-Panel.bat sitting at the top level, next to a folder — leave them where they are relative to each other.

If Windows shows a blue "Windows protected your PC" warning the first time you double-click the .bat file — that's normal for any downloaded .bat file. Click More info, then Run anyway.

Step 2

Run the Super Admin Panel

1

Double-click Start-Super-Admin-Panel.bat

A black window opens and does the setup for you. The very first time, it installs some files and can take a couple of minutes — every time after that, it takes just a few seconds.

2

Your browser opens automatically

It'll land on http://localhost:3200. If it doesn't open by itself, just go to that address yourself.

This runs on a different address (3200) than the regular Admin Panel (3100) — the two can be installed and run side by side on the same computer without conflicting.

Logging in

Signing in

This is a demo build, so there's nothing to remember:

→

Easiest: click "Skip — continue as demo staff"

Right on the sign-in page — takes you straight in, already recognized as a super admin.

→

Or type any email and any password

The demo doesn't check credentials — anything typed into both fields will sign you in.

What's different here

Fleet & Staff and Roles

Look for the "Super admin only" label near the bottom of the sidebar — these two sections don't exist in the regular Admin Panel:

→

Fleet

Provision new hardware units, reassign a device to a different user, push a firmware version, mark a unit replaced, or force-unpair a lost device.

→

Staff & Roles

Promote a regular user to admin or super admin, change an existing staff member's role, or remove their staff access entirely.

If something goes wrong

Troubleshooting

"Node.js was not found on this computer" — install it from nodejs.org (the LTS version), then double-click the .bat file again.
Browser opens but shows "can't reach this page" — the server was still starting up. Wait a few seconds and refresh, or check the black window for errors.
Nothing seems to happen when you double-click — check for a blue Windows SmartScreen warning that may have popped up behind other windows; click More info → Run anyway.
To stop the panel, just close its black window. To start it again later, double-click the same .bat file — no need to reinstall anything.
